# 视觉系统、视觉资产决策与文案数据规范

---

## 一、基准视觉系统与定制原则

> **最高优先级**：若用户已有原 PPT 模板或已确认的封面/样页，必须先完全服从既有视觉系统，再在其中提升信息密度与图形质量。无既有模板时，按主题与受众独立设计，不机械照搬过往配色。

### 1. 画幅与坐标参考
- **画幅**：默认 16:9，推荐以 `1280 × 720` 作为相对设计坐标（或 `13.333 × 7.5 in` / `20 × 11.25 in`；换画布尺寸时，字号、线宽、边距必须按比例重算，严禁直接照抄绝对像素/磅值）。
- **页面安全区**：
  - 左右安全边距：约占页宽 `3.5%–5%`；
  - 顶部标题与章节区：约占页高 `12%`（若含顶部章节条 + 单行主标题 + 引导句，正文主体通常落在页高 `22%–84%` 区间）；
  - 底部页脚/页码/来源区：预留不少于页高 `5%`；
  - 若使用右侧纵向章节导航栏，预留约 `8%–9%` 宽度作为导航及隔离带。

### 2. 色彩语义化规范
避免“彩色乱涂”或“白底就只能黑白”。为整套建立 1 套主色 + 语义辅助色：
- **底色**：纯白、极浅暖灰或浅冰蓝（正式答辩/政企汇报优先高对比浅底，保证投影清晰；暗色主题仅在发布会/特定视觉要求时使用）。
- **颜色语义映射**（确保全套一致）：
  - **主深色**（如深海军蓝/深炭蓝）：主结论、主标题、核心框架；
  - **主强调色**（如科技蓝/青绿）：流程推进、核心能力、当前章节高亮；
  - **正向语义色**（如青绿/薄荷绿）：优势、收益、可用动作、验证通过项；
  - **警示语义色**（如珊瑚红/砖红）：痛点、风险、限制条件、人工兜底边界；
  - **提醒/阶段色**（如琥珀金/暖黄）：关键节点、阶段高亮、待评估项、少量点缀。
- **局部变色检查**：架构图分层或对比图内部需要多种颜色区分层级时，必须同时检查**局部可辨识度**与**全套色彩协调性**，防止某一页突然“跳出画风”。
- **同类组件一致性**：同类型图形/模块（如两页里的鱼骨图或卡片组）必须在透明度、描边粗细、圆角半径、阴影强度与标题条样式上保持一致。

### 3. 兼容字体与排版底线
- 优先使用跨平台高兼容无衬线字体：`Noto Sans CJK SC`、`Microsoft YaHei`、`Segoe UI`、`Arial`（若明确面向特定品牌/印刷环境可按需指定）。
- **硬性禁令**：零乱码、错别字、缺字、方框字（豆腐块）、英文拼写错误、字符重叠、文字被边框遮挡或溢出画布。
- **标题铁律**：主标题必须**单行、结论式观点句**；放不下就精炼措辞或调整版式，严禁压扁字形、过度缩字号或任其折成两行。

## 二、每页视觉资产决策矩阵

开工前必须明确本页主视觉资产，避免因省事而满屏只剩文本框和矩形框。每页至少应满足下列资产之一（极少数纯政策原文或严肃明细表除外）：

| 内容场景 | 优先视觉资产 | 核心目的 |
|---|---|---|
| 抽象概念、技术底座、能力演进、未来图景 | **AI 无文字主题插画 / 三维隐喻主体** | 建立强记忆点，把抽象概念具象化 |
| 历史演进、阶段升级、代际跨越 | **AI 无文字阶段视觉 + 后期原生矢量时间轴** | 让阶段跃迁直观可感而不单调 |
| 具体产品、平台、公司、生态案例 | **官方可核验 Logo / App 图标 / 经典形象 / 真实截图** | 提供真实识别锚点，建立可信度 |
| 数字趋势、性能对比、占比、实验验证 | **真实可解释数据图表 / 定性能力矩阵** | 用视觉证据替代大段文字解释 |
| 业务流程、闭环治理、审批流、系统架构 | **原生矢量流程图 / 泳道 / 分层架构 / 决策树** | 清晰界定动作、流向、层级与责任边界 |
| 真实业务现场、使用对象与落地情境 | **AI 无文字场景插画，或经授权的真实照片** | 让观众瞬间代入使用人群与场景 |

> **四类资产协同次序（以典型产品/方案页为例）**：
> `官方真实识别符号 → 结构化原生内容与矢量关系 → 适度无文字场景插画辅助 → 页脚数据来源与边界声明`

## 三、AI 生成插画与图标（Icon）硬性标准

AI 图像生成（如 Imagen、Nano Banana、DALL-E 等协同 Skill）是**主动内容表达能力**，而非可有可无的装饰，但必须遵守以下硬约束：

1. **绝不含文字**：生成提示词必须强约束 **NO text, NO letters, NO numbers, NO logos, NO tables, NO readable UI**。所有中英文、数字、刻度与流程标签一律后期原生叠加。
2. **每张图必答“为什么是它”**：画面必须对应本页的**核心对象、作用过程或使用场景**之一。
   - *反面教训*：讲多维融合分析时放无关的“人体解剖图”；在不同主题页反复套用泛泛的“科技蓝芯片/发光立方体/机械臂”。
3. **整套提示词风格锁定**：为同一套 PPT 定义统一的 **Visual Prompt Lock**，锁定：主辅色盘、光照方向、材质质感（如磨砂玻璃/等距矢量/柔和 3D/扁平轻质感）、镜头透视、画面颗粒度与背景纯度（优先纯白或与页面无缝融合的干净底色），避免每页像拼凑自不同作品集。
4. **预留构图与文字共存区**：生成前明确指定画幅横纵比、主体偏置方向（如主体居右、左侧 40% 纯净留白供排版文字）。
5. **逻辑由矢量补全**：如果插画承载“演进、协同、流程”含义，必须由后期原生矢量箭头、时间轴和文字标签补全逻辑，不能让观众靠猜图理解含义。
6. **精致不等于过度炫技**：光效和细节不得抢过标题与核心内容，气质需匹配正式汇报/学术答辩场合。章节过渡页插画应**同系列风格、不同章节主题**。
7. **插画与 Icon 分工**：插画负责塑造整页场景或核心隐喻；小 Icon 仅用于修饰局部列表条目或节点细节，**绝不用一堆零散小图标替代整页主视觉**。不要把照片、写实 3D、粗线扁平图标和低清截图混搭在同一页。
8. **不合格即淘汰**：生成图若出现模糊、文字残影、裁切怪异、画风脱节，必须重生成或剔除，绝不勉强拼接。

## 四、官方品牌资产与事实表达边界

1. **真实产品必须使用真实资产**：介绍具体产品（如某大模型、软件、平台）时，主动通过搜索/资产 Skill 获取官方可核验的 Logo、应用图标、经典角色或官方产品图；**严禁手绘、AI 捏造或仿制真实品牌 Logo 和产品 UI 截图**。
2. **五层概念严禁混为一谈**：介绍科技/AI 生态时，清晰区分 **公司 / 模型 / 产品 / 平台 / 智能体** 五个层级。
3. **工具介绍五要素**：介绍具体工具或系统时，尽可能交代清楚：**定位、典型能力、适用任务、限制条件、人工审核与责任边界**。绝不将“系统可执行”表述为“可替代人工决策和最终责任”（尤其在隐私、权限、代码提交、对外发布、医疗/政企合规等高风险环节）。
4. **时效与来源标注**：发布日期、模型排名、价格套餐、性能数据、功能清单等易变信息必须核对官方最新资料，来源写入备注或页脚，并注明“以官方最新发布为准”。严禁引用无来源精确数字或过时版本参数。

## 五、文案精炼、技术写作与数据图表规范

### 1. 详实不堆字，简洁不空洞
- **结论式标题**：不写“背景介绍”“工具对比”这类纯名词标题，改写为表达核心判断的一句话（如“工具选型不是比较谁更强，而是先判断任务属于哪一类”）。
- **场景化密度控制**：
  - *汇报/培训图形化页*：正文单元采用“短标题 + 1–3 条短句”，单单元通常控制在 **35–50 个中文字符** 内；超量时拆分单元、拆页或移入演讲备注，绝不靠无限缩字号硬塞。
  - *答辩/专业评审深度页*：允许更高信息密度，让专家一眼看到实质方法与工作量，通过信息分组和空间层级组织文字，而非把核心技术删成一句空口号。
- **删除绕话与冗余前提**：既然整页已在讲某模块/算法，删掉“在 XX 中如果采用……”这类重复标题语境的铺垫，以及“我们希望体现……”等虚词，直接陈述**动作、依据与结果**。
- **结尾价值四层递进**：拒绝“降本增效、赋能未来”万能套话。按 **谁在什么场景使用 → 对个人/团队的直接作用 → 对组织/行业的具体价值 → 回扣开篇问题/画面** 逐层升华。

### 2. 技术表达规范
- **技术名词必有角色**：不允许堆砌框架名、模型名或技术 Logo 墙；每个提及的技术名词必须交代它在本页的**输入、承担作用与输出**。
- **架构与技术栈分清**：
  - **系统架构**回答“有哪些层级、模块如何协作、数据如何流转”；
  - **技术栈**回答“各层/模块选用了哪些具体工具、语言或框架实现”。
  - 两者可同页分栏呈现（如左架构、右技术栈、底运行链路），绝不混写成同一层级。

### 3. 数据图表规范
- **选代表性真实证据，不复述整份实验报告**：挑选最能支撑本页结论的真实数据，必须标清：**比较对象、指标方向（越高越好/越低越好）与单位、数据范围/条件/样本量、数据来源**。
- **严禁伪造与失真**：没有可靠量化数据时，不编造精确小数，可改用定性“能力维度图”“任务匹配矩阵”并写明评估口径；图表严禁压扁、拉伸、截断坐标轴标签。
- **真实截图把关**：系统界面截图页应让清晰界面做主体，检查小字可读性与边缘裁切；如原截图分辨率低或存在裁切缺陷，优先重截高清图或做局部放大标注。
