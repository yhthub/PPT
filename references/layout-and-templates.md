# 版式选型、19 种可复现模板与五页视觉节奏规则

> 核心原则：**内容关系决定主导版式，绝不为套用漂亮图形而虚构时间顺序、因果链路、循环关系或数据差异。**

---

## 一、信息关系 → 版式映射表

先判定本页信息的核心逻辑关系，再从下表选择主导版式，规避错误匹配：

| 信息关系 | 优先主导版式 | 严禁/不宜使用 |
|---|---|---|
| 阶段、月份、里程碑、责任人、进度 | 波浪时间线、甘特图、阶段阶梯 | 环形图、SWOT |
| 可重复迭代机制、治理闭环、持续改进 | 环形六步闭环、双周期、跑道型流程 | 单向流程箭头 |
| 输入—处理—输出、端到端工作流 | 泳道图、横向流程、胶囊跑道 | 金字塔 |
| 目标分层、能力成熟度、从基础到高阶 | 金字塔、冰山模型、阶梯递进 | 环形闭环 |
| 问题根因、内外因素、影响因素 | 鱼骨图、因果矩阵、左右对照 | 纯时间线 |
| 战略方向下的多项支柱与指标 | 屋形战略总览、中心辐射、半圆扇区 | 甘特图 |
| 四象限诊断或策略组合 | SWOT、2×2 矩阵 | 线性流程 |
| 多模块围绕一个中枢协同 | 六边形中枢、中心辐射、花瓶收敛 | 甘特图 |
| 两组目标、两条路径、两类对象比较 | 左右镜像、双侧弧形、双轨对照 | 单一中心辐射 |
| 多主体共享底座再分化方向 | 上方共同基础 + 下方多条分支 | 拆成多页重复铺陈 |
| 多维数据总览、指标与图表并列 | 屋形目标 + 关键指标 + 小图表 | 大型流程图 |
| 一组成果或任务的全景拆解 | 半圆扇区、玫瑰图、放射式结构 | 高密度大表格 |
| 科研系统、技术架构、层级接口 | 分层架构（架构与技术栈分区）、前尖指向 | 装饰性数据卡片 |
| 发展史、产品演进、能力升级 | 二维/三维时间轴、阶段里程碑、阶梯演进 | 无逻辑卡片拼贴 |
| 选型与决策 | 决策树、条件筛选、任务—工具匹配表 | 不带判断口径的产品罗列 |
| 案例与系统能力说明 | 真实界面主体、场景任务单、前后对比、步骤复盘 | 抽象结构图 |

## 二、19 种可复现页面模板库

复用时仅复现**信息组织方式与视觉节奏**，严禁复制过往示例中的文字、品牌、配色或虚构数据：

### A. 成果与全景类
| 编号 | 模板名称 | 适用关系与主视觉要点 |
|---|---|---|
| **A1** | 中心靶心 + 双侧行动项 | 一个核心中枢驱动两侧行动或成果；中心体量最大，左右各 3 项对称呼应 |
| **A2** | 半圆扇区成果盘 | 5–8 项并列成果或全景拆解；扇区内置核心数字/序号，解释说明置于外侧 |
| **A3** | 指标星环 / 舞台聚光 | 2–4 个高光事项与 6–8 个支撑数据点；中央主题聚焦形成强视觉锚点 |
| **A4** | 屋形战略总览 | 年度目标、战略支柱、经营指标；顶部屋檐统一愿景，下方支柱列等宽对齐 |

### B. 时间与流程类
| 编号 | 模板名称 | 适用关系与主视觉要点 |
|---|---|---|
| **B1** | 波浪时间线 | 5–7 个阶段节点；节点说明上下交错排布，保持流畅节奏，不做成死板表格 |
| **B2** | 环形六步闭环 + 双侧说明 | PDCA、治理循环、持续优化；环心放置最终产出或目标，外侧按序补充说明 |
| **B3** | 无限循环 / 双周期复盘 | 两个周期互相反馈联动；**仅在存在真实双周期反馈关系时使用** |
| **B4** | 跑道型端到端流程 | 闭合业务链路、自动化流水线、双向协同；外圈连续方向段串联各阶段 |
| **B5** | 甘特排期矩阵 | 跨团队任务、责任人、时间窗口与进度；横条长度精确表达时长 |

### C. 结构与分析类
| 编号 | 模板名称 | 适用关系与主视觉要点 |
|---|---|---|
| **C1** | 金字塔成长路径 | 由基础到高阶、优先级、证据等级、能力成熟度；**不可用于表示并列部门** |
| **C2** | 冰山模型 | 显性/隐性因素、表层现象与底层机制；水面分割线必须清晰、上下对比强烈 |
| **C3** | 鱼骨根因分析 | 问题诊断、风险归因与因果链；主骨直指结果，上下均匀分列原因大类 |
| **C4** | SWOT 四象限联动 | 内外部战略诊断；每个象限必须给出 2–3 条具体事实依据，拒绝空话 |
| **C5** | 六边形中枢 / 几何协同 | 多模块围绕统一中枢协作；只保留主链路箭头，避免连线交错成蜘蛛网 |
| **C6** | 分层架构 / 前尖指向 | 科研框架、技术路线、输入—核心—输出；上下配置支撑平台与接口层，架构层与技术栈分清 |
| **C7** | 花瓶收敛模型 | 两组方法、多源数据或多重约束向一个核心机制汇聚产出 |
| **C8** | 横向阶梯 / 多层证据 | 多尺度研究、渐进式证据、递进价值（如个人→组织→行业→社会）；左中右层层深入 |

### D. 对照与聚焦类
| 编号 | 模板名称 | 适用关系与主视觉要点 |
|---|---|---|
| **D1** | 双侧弧形定位 | 两组对象、两条路径、责任与机会的镜像对照；左右主次清晰或对称平衡 |
| **D2** | 玫瑰图 / 放射成果回顾 | 6–8 个同级主题或维度成果；每个扇瓣位置需清晰回指外侧对应说明 |

> **选型底线**：鱼骨图只讲因果，甘特图只讲时间与进度，金字塔只讲递进/分层，闭环只讲可重复机制。绝不把普通并列清单套进漂亮图形后伪称存在上述关系。

## 三、连续五页结构变化硬性规范

### 1. 制作前必填：《五页版式分配表》
每制作一个连续 5 页单元前，必须先输出并检查下表；若出现两个同类主导版式（例如两页都是“双栏卡片”或两页都是“中心辐射”），**必须在制作前更换结构**，禁止事后只改颜色或挪位置敷衍：

```markdown
| 页码 | 叙事任务 | 主结论（单行观点） | 信息关系 | 主导版式（精确到模板/轮廓） | 视觉资产决策 | 避让项（相对前后页） |
|---|---|---|---|---|---|---|
| P1 | 例：开篇主张 | ... | 概念锚定 | 主张 + 大视觉主体 | 无文字主题插画 | 避开密集多列文字 |
| P2 | 例：发展演进 | ... | 阶段演进 | B1 波浪时间线 | 阶段插画 + 矢量轴 | 避开中心构图 |
| P3 | 例：体系架构 | ... | 层级协作 | C6 分层架构 + 右侧技术栈 | 矢量架构图 | 避开纯线性时间轴 |
| P4 | 例：能力评测 | ... | 横向对比 | 真实数据图表主导 + 对照矩阵 | 真实实验/基准图 | 避开多层堆叠盒子 |
| P5 | 例：落地选型 | ... | 条件决策 | 决策树 / 泳道流程 | 官方图标 + 矢量流程 | 避开纯数据图和卡片阵列 |
```

### 2. 相邻页面避重与节奏规则
- **相邻两页零同构**：禁止连续两页出现同一种中心辐射图、同一种左右双栏卡片、同一种横向四步流程、同一种多列分类卡片，或机械重复的“标题条 + 等宽卡片 + 页脚”（仅当明确属于同一连续流程拆页时，才可受控延续并强化承接提示）。
- **相邻三页四选二变化**：任意连续三页，至少改变以下四项中的两项：
  1. **主图形轮廓**（环形 / 线性 / 阶梯 / 矩阵 / 分层 / 放射 / 非对称大小块）；
  2. **信息流方向**（横向 / 纵向 / 环形 / 中心辐射 / 对角递进）；
  3. **图文比例**（大图少字 / 图文均衡 / 图表主导 / 真实界面主导）；
  4. **留白重心**（左重右轻 / 上重下轻 / 中心聚焦 / 边缘舒展）。
- **密度呼吸与构图切换**：
  - 中心构图页之后，优先切换为边缘构图或线性构图；
  - 高密度数据/架构页之后，优先切换为低密度核心结论页、章节转场页或主视觉叙事页；
  - 每 3–5 页安排一次视觉缓冲（章节过渡、核心大字结论或大幅场景插画），防止观众视觉疲劳；
  - 对非等权模块（如前置支撑 vs 核心创新），**用面积和位置体现主次**（如左 35% 前置 + 右 65% 核心），切忌机械三等分。

## 四、空间、留白与信息组对齐原则

1. **留白是有组织的呼吸，不是空着不管**
   - 遇到大块空洞空白，按以下顺序诊断，**切勿条件反射“再塞一张图”**：
     1) 是否核心内容不足、缺少必要依据或边界？
     2) 关键图表/真实界面是否画得太小看不清？
     3) 对应图形与解释文字是否离得太远？
     4) 能否让现有节点与文字向留白方向自然舒展？
     5) 这块留白是否在主动帮助观众分组与聚焦？
2. **图文结成信息组（Proximity）**
   - 把“一个子观点 + 解释文案 + 对应图形/图标”当作不可分割的信息组来排版。
   - 图必须紧邻它解释的文字，绝不把文字全挤在左侧、右侧孤立堆一堆小 icon 让观众跨半页猜测关系。
   - 居中或左对齐必须服从阅读逻辑和层级归属，禁止把所有元素机械居中。
3. **绘制与栅格纪律**
   - 同类元素严格等宽、等高、等间距；跨区域文本左边缘、标题基线、分隔线与连接线端点对齐栅格。
   - **绘制层级顺序**：底色/区域容器 → 底层连接线与箭头 → 节点形状/卡片 → 图标与原生文字。
   - 箭头方向语义全页统一，连接线绝不越界、不断裂、不穿过文字或卡片。
